**Tech:** JavaScript, HTML/CSS · [Source](https://github.com/dyun2028/browser-wallpaper-app)

- Built a browser app that shows the pictures in a folder full screen, like a desktop wallpaper, with no server or install needed.
- Implemented 18 transition effects (crossfade, 3D flip, cube, shatter, glitch and more), each picked at random with random directions or origins.
- Added autoplay, shuffle, fit modes, keyboard and swipe controls, and drag-and-drop for choosing a folder, with settings remembered in the browser.
