**Tech:** Flask, Nginx, Gunicorn, SQLite, HTML/CSS, JavaScript, Supabase · [Live at danielyun.dev/imageboard/](/imageboard/)

- Built a full-stack imageboard, styled with open-CSS from GitHub.
- Configured Gunicorn and port forwarding, and self-hosted it on a personal machine.
- Added templates, 4 different boards, image uploading, thumbnails and text, all stored locally in SQLite.
- Later ported it to a static page at [danielyun.dev/imageboard/](/imageboard/), using Supabase (Postgres and Storage) in place of the self-hosted server and SQLite.
